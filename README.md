## 🛠 Prerequisites
Before starting, ensure you have:
- A personal computer (Windows / macOS / Linux)
- A stable internet connection
- A Google account

## ⚙️ Developer Environment Setup

Follow these steps sequentially to prepare your environment:

1. **Install Git**
   - Download Git from [git-scm.com](https://git-scm.com/).
   - Open your terminal or command prompt and verify the installation:
     ```bash
     git --version
     ```

  - **Primary Use Case:** Writing, debugging, and editing code across various programming languages like Web Dev, Python, and Flutter[span_3](start_span)[span_3](end_span).
