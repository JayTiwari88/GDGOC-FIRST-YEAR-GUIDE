# Contribution Guidelines

Thank you for contributing to the GDG Onboarding Guide! Please follow these standards when making edits.

## Documentation Standards
- "Format: All files must be written in valid GitHub Flavored Markdown (GFM).
- "Tone: Professional, beginner-friendly, and concise.
- "Code Snippets: Always wrap code blocks with language identifiers (e.g., ```bash or ```json).
- "Links: Ensure all external links open correctly and point to official sources
